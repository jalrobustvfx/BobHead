# Before and after example

- **[before.mp4](before.mp4)** — the supplied `Tonigh_v003.mp4` source footage, with original dialogue. Download this file and upload it in BobHead to test the app. Choose **5 seconds**.
- **[after.mp4](after.mp4)** — the enlarged-head result generated by BobHead from that source footage, with the original dialogue.

To download either file, open it on GitHub and click **Download raw file**. If the video opens in your browser, use **Save video as**.
